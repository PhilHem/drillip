# Drillip brand assets

The mark combines an open lowercase `d` with an amber event marker. The
wordmark uses custom geometric letter shapes. All artwork is SVG geometry;
there are no font, script, or external asset dependencies.

- `icon.svg`: standalone mark, with its own background for either theme.
- `wordmark-light.svg`: dark lettering for a light background.
- `wordmark-dark.svg`: light lettering for a dark background.

The main README selects the wordmark through a `picture` element and uses the
light version as its fallback. Keep geometry identical between both versions.
The palette is deep green (`#103B3B`), pale green (`#ECF5EC`), and amber
(`#FFB562`), with a green border (`#29605B`).
